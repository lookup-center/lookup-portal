가입부터 결과 저장까지

1가입과 승인

처음 방문했다면 이메일을 입력하고 ‘처음 이용합니다’를 선택하세요. 받은 최신 인증 코드를 입력하면 승인 대기 상태를 확인할 수 있습니다. 관리자 승인 후 ‘승인 상태 새로고침’을 누르세요. 이미 가입했다면 체크하지 않고 로그인합니다.

2설치와 앱 로그인

Windows 설치 파일을 실행하고 설치 위치, 기존 버전, 바로가기를 확인하세요. 설치 후 앱에서 같은 이메일로 코드를 받아 로그인합니다. Windows 10·11 64비트, Microsoft Edge와 인터넷 연결이 필요하며 Python 별도 설치는 필요 없습니다.

3한 건 조회

법원, 사건번호, 당사자명, 은행과 계좌번호를 입력합니다. 저장 폴더를 선택하고 ‘한 건 조회’를 누릅니다. 조회 권한이 있는 사건의 정보를 입력하세요.

4대량조회

CSV 양식의 제목줄을 유지하고 사건당 한 줄씩 입력하세요. 은행코드와 계좌번호는 텍스트로 다뤄 앞자리 0을 보존합니다. ‘대량 저장 폴더 선택’ 후 ‘CSV 목록 열기’로 실행하세요.

5결과 확인

단건은 법원명·사건번호 폴더, 대량은 목록조회_날짜_시간 폴더에 저장됩니다. 조회결과.xlsx는 조회요약, 일반내용, 진행내용, 채권자현황, 변제현황, 시도이력 6개 시트로 구성됩니다. 모든 시트에 법원명과 사건번호가 표시됩니다. 화면 이미지는 일반내용·진행내용·변제현황으로 저장하며, 화면이 없거나 오류가 나면 일부 파일이 없을 수 있습니다.

!문제가 생겼을 때

  • 인증 코드가 만료되면 새 코드를 받고 가장 최근 메일의 숫자를 입력하세요. 재발송은 60초 후 가능합니다.
  • 승인 대기·정지·만료는 관리자에게 확인하세요.
  • 회원 서버에 연결되지 않으면 조회가 중단됩니다. 이미 받은 결과는 저장하며, 연결 복구 후 앱을 다시 실행하세요.
  • 조회 오류는 결과 파일의 오류와 시도이력을 확인하세요. 일시적 오류는 최초 시도 후 최대 3회 재시도합니다.
  • 설치 경로가 너무 길다는 안내가 나오면 기본 경로를 선택하세요.

+업데이트와 제거

업데이트는 저장 설정을 이어받고 이전 결과를 보존합니다. Windows 설정 → 앱 → 설치된 앱 → 사건조회 → 제거로 프로그램을 제거할 수 있습니다. 결과·설정·수정된 파일과 이전 수동 설치판은 남습니다.
